RETAIL PERFORMANCE & INSIGHTS WEBSITE
BBA Business Analytics Project | Integral University

WHAT YOU NEED
1. Visual Studio Code (VS Code) 
2. Google Chrome or another modern browser
3. Internet connection for Google Fonts and Chart.js CDN

HOW TO RUN
1. Extract the ZIP file.
2. Open VS Code.  
3. Select File > Open Folder.
4. Select the extracted "retail-performance-website" folder.
5. Open index.html.
6. Right-click inside index.html and choose "Open with Live Server".
   If Live Server is not installed:
   - Click the Extensions icon in VS Code.
   - Search for "Live Server" by Ritwick Dey.
   - Install it, then repeat step 6.
7. The website should open in your browser.

FILES
index.html  - Website page structure and content
style.css   - Website design, colours, layout and responsive styling
script.js   - Interactive charts and navigation behaviour

IMPORTANT DATA NOTE
This website is built from the aggregate figures shown in the supplied
12-page Business Intelligence presentation. It is a website version of
the reported dashboard, not a live database application.

The presentation does not provide the full transaction-level dataset,
exact monthly values, or numerical discount breakdowns. Therefore this
version does not invent those values. Monthly trend and discount analysis
are described in the project text but are not plotted as fabricated charts.

To update a figure, edit the relevant values in script.js and the KPI text
in index.html. The chart values are expressed in millions (M), except the
KPI order and quantity cards.

TECHNOLOGIES
HTML, CSS, JavaScript, Chart.js
